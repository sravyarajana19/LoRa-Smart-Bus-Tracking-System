# 📡 LoRa Smart Bus Tracking System

## 📌 Project Overview

The **Real-Time Bus Tracking System using LoRa Technology** was developed as my **Final Year Engineering Project** during my B.Tech in Electronics and Communication Engineering.

The project uses **LoRa (Long Range Communication)** and **GPS** to monitor and transmit the real-time location of a bus over long distances with low power consumption.

---

## 🛠 Technologies Used

- Arduino UNO
- LoRa Module (RYLR896-SX1276)
- GPS Module (NEO-7M)
- Embedded Systems
- IoT
- Wireless Communication

---

## 🚀 Key Features

- Real-time bus location tracking
- Long-range wireless communication
- GPS-based positioning
- Low-power communication
- Embedded system implementation
